# Contrats

Les contrats du dépôt, au sens du kit `_Generic` : les engagements vérifiables que la bibliothèque tient
envers ses consommateurs et que les agents doivent respecter.

- [csp-contract.md](csp-contract.md) : contrat CSP stricte (aucun style ni script en ligne, écritures
  CSSOM seulement, responsabilités de l'hôte).
- [accessibility-contract.md](accessibility-contract.md) : contrat d'accessibilité (focus, contrastes,
  motifs clavier, exceptions documentées).

Les règles de codage (`STD-*`) du dépôt ne sont pas ici : elles restent dans le registre local du
dépôt, adapté du kit.
