# Contrats

Ce répertoire accueillera les contrats du dépôt, au sens du kit `_Generic` : les engagements
vérifiables que la bibliothèque tient envers ses consommateurs et que les agents doivent respecter.

Il est vide pour l'instant. Les contrats existants vivent encore à la racine de `docs/` et leur
déplacement ici attend la validation de l'utilisateur (voir [PLAN-001](../plans/PLAN-001-remise-equerre-kit.md),
lot 3) :

- `docs/csp-contract.md` : contrat CSP stricte ;
- `docs/accessibility-contract.md` : contrat d'accessibilité.

Les règles de codage (`STD-*`) du dépôt ne sont pas ici : elles restent dans le registre local du
dépôt, adapté du kit.
