# Rétrospectives

Ce répertoire conserve les retours d'expérience durables issus des incidents, des migrations et des
travaux importants du dépôt.

## Nomenclature

- Format obligatoire : `RET-NNN-sujet-descriptif.md`.
- `RET` est le préfixe sur trois lettres des rétrospectives.
- `NNN` est un numéro séquentiel sur trois chiffres, attribué dans l'ordre du registre ci-dessous.
- Le sujet est explicite, en minuscules et kebab-case.
- La date et le contexte appartiennent au contenu du document, pas à son nom de fichier.
