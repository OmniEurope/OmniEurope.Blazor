# Sécurité

Ne publiez pas de vulnérabilité dans une issue publique. Utilisez la fonctionnalité privée « Report a vulnerability » du dépôt GitHub lorsque celle-ci est activée.

Les régressions CSP, les injections de balisage et les contournements des garde-fous d'attributs sont traités comme des problèmes de sécurité.
