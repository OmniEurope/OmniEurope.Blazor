# Sécurité

## Versions prises en charge

Seule la dernière version publiée reçoit des correctifs de sécurité. Les versions antérieures doivent être mises à niveau avant l'analyse d'un rapport.

## Signaler une vulnérabilité

Ne publiez jamais une vulnérabilité dans une issue ou une discussion publique. Utilisez le formulaire privé permanent [Signaler une vulnérabilité](https://github.com/OmniEurope/OmniEurope.Blazor/security/advisories/new). Si GitHub n'affiche pas ce formulaire, n'exposez aucun détail : ouvrez uniquement une issue publique demandant l'activation du canal privé, puis attendez la réponse du mainteneur avant de transmettre le rapport.

Le mainteneur accuse réception sous 3 jours ouvrés, fournit une première évaluation sous 10 jours ouvrés et communique ensuite au moins tous les 7 jours jusqu'à la résolution. La publication coordonnée intervient après disponibilité du correctif, sauf nécessité de protéger immédiatement les utilisateurs.

Les régressions CSP, les injections de balisage, les URI actives et les contournements des garde-fous d'attributs sont traités comme des problèmes de sécurité.
